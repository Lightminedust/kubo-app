Kubo is a desktop app for Windows and Linux. It connects to your server over SSH and gives you its files, services, ports, firewall, Docker containers, Redis and packages in one interface. Nothing is installed on the server.

Kubo est une application de bureau pour Windows et Linux. Elle se connecte à votre serveur en SSH et réunit ses fichiers, services, ports, pare-feu, conteneurs Docker, Redis et paquets dans une seule interface. Rien n'est installé sur le serveur.

Overview Présentation

What the terminal doesn't show you

Ce que le terminal ne vous montre pas

A service that won't restart after a reboot. A database port open to the internet. A container slowly eating memory. All of it is visible from a shell, if you know which command to run and when. Kubo runs those commands for you and shows the result.

Un service qui ne redémarrera pas au prochain reboot. Un port de base de données ouvert sur Internet. Un conteneur qui consomme de plus en plus de mémoire. Tout cela se voit depuis un shell, à condition de savoir quelle commande lancer, et quand. Kubo les lance pour vous et affiche le résultat.

The terminal stays available inside the app. Anything that changes the server asks for confirmation first.

Le terminal reste disponible dans l'application. Toute action qui modifie le serveur demande une confirmation.

Know which ports are really exposed

Sachez quels ports sont vraiment exposés

A port that is listening is not necessarily reachable. Kubo compares each listening port with your firewall rules and tells you whether it is open to the internet, blocked, or local only.

Un port en écoute n'est pas forcément accessible. Kubo compare chaque port avec les règles de votre pare-feu et vous dit s'il est ouvert sur Internet, bloqué, ou seulement local.

It reads UFW, firewalld, nftables and iptables, and names the process, PM2 app or Docker container behind each port. If it cannot read the rules, it says so.

Il lit UFW, firewalld, nftables et iptables, et nomme le processus, l'application PM2 ou le conteneur Docker derrière chaque port. S'il ne peut pas lire les règles, il le dit.

Running now does not mean running after a reboot

Actif maintenant ne veut pas dire actif après un reboot

A service can be running without being enabled at boot. It works until the next restart, then it is gone. Kubo checks both states for every service and sorts them: failed, won't survive a reboot, enabled but stopped, running, idle.

Un service peut tourner sans être activé au démarrage. Il fonctionne jusqu'au prochain redémarrage, puis disparaît. Kubo vérifie les deux états pour chaque service et les classe : en échec, perdu au prochain reboot, activé mais arrêté, actif, inactif.

Select a service to see what it depends on and what depends on it. Start, stop, enable, disable. Limit its memory or CPU without restarting it. Override its settings without touching the original unit file. Turn any script on the server into a service.

Sélectionnez un service pour voir ses dépendances et ce qui dépend de lui. Démarrez, arrêtez, activez, désactivez. Limitez sa mémoire ou son CPU sans le redémarrer. Modifiez ses réglages sans toucher au fichier d'origine. Transformez n'importe quel script du serveur en service.

Kubo refuses to stop SSH or the network. You would lose access to the server.

Kubo refuse d'arrêter SSH ou le réseau. Vous perdriez l'accès au serveur.

Security Sécurité

Built to hold root access

Conçu pour détenir un accès root

Kubo needs SSH access, and sometimes root. This is how it handles them.

Kubo a besoin d'un accès SSH, parfois root. Voici comment il les gère.

Kubo only connects to the servers you add. Nothing is sent anywhere else.

Kubo ne se connecte qu'aux serveurs que vous ajoutez. Rien n'est envoyé ailleurs.

  • 01
    Host keys verifiedOn first connection, the server's fingerprint is shown for approval. If the key changes later, the connection is refused.
  • 01
    Clés d'hôte vérifiéesÀ la première connexion, l'empreinte du serveur est affichée pour validation. Si la clé change ensuite, la connexion est refusée.
  • 02
    Passwords not keptPasswords stay in memory only while they are needed, then they are erased. They are saved only if you ask, encrypted with Windows DPAPI.
  • 02
    Mots de passe non conservésLes mots de passe restent en mémoire le temps nécessaire, puis sont effacés. Ils ne sont enregistrés que si vous le demandez, chiffrés avec DPAPI sous Windows.
  • 03
    Root on demandKubo never elevates on its own. You enable root once per session, and every window shows Kubo_root while it is on.
  • 03
    Root à la demandeKubo ne passe jamais root de lui-même. Vous l'activez une fois par session, et chaque fenêtre affiche Kubo_root tant qu'il est actif.
  • 04
    No surprise deletionsDestructive actions require typing the name of the target. Root commands are fixed templates, never built from your input.
  • 04
    Aucune suppression par erreurLes actions destructives demandent de retaper le nom de la cible. Les commandes root sont des modèles fixes, jamais construites à partir de votre saisie.
  • 05
    Local logEvery command is logged on your computer. Outputs and file contents are never stored.
  • 05
    Journal localChaque commande est journalisée sur votre ordinateur. Les sorties et le contenu des fichiers ne sont jamais enregistrés.
